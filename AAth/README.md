# Age Authenticator 🔐

A beginner-friendly Python project that checks a user's age and determines whether they are allowed to enter a club.

## 📌 About the Project

This project was created to practice basic Python programming concepts, including:

- User input with `input()`
- Type conversion with `int()`
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Displaying messages with `print()`

## ⚙️ Requirements

- Python 3
- A terminal or Python-compatible code editor

## 🚀 How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the script:

   ```bash
   python3 "Age Authenticator.py"
   ```

4. Enter your name and age when prompted.

## 💻 Example

```text
Name: Alex
Age: 20

____________________ You can enter the club ____________________
```

## 🎯 Learning Goals

The main goal of this project is to understand how Python makes decisions based on user input and conditions.
